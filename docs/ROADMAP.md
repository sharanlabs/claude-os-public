# Roadmap

This is a small public toolkit, not the entire personal claude-os environment. Work is prioritized by demonstrated usefulness to another maintainer.

## Included in this release

- Standard-library evaluator and task linter.
- Synthetic examples and CLI regression tests.
- Selected review skills with retained licenses and provenance.
- Setup, architecture, contribution, and evaluation-limit documentation.

## Next: prove usefulness with another maintainer

Run one independent pilot on a permitted real change. Publish the setup, human-established expected findings, failures, clean controls, costs, and consented feedback. Turn reproducible failures into regression cases. Do not claim adoption before it occurs.

## After the pilot

1. Add a documented Codex integration for generating review candidates, with explicit budgets and human approval before any repository mutation.
2. Evaluate held-out defects and clean changes, reporting false positives and missed defects as well as successes.
3. Make combined deterministic/judge reports easier to audit.
4. Publish additional original controls only when their dependencies, installation, tests, and limits are portable.

Additional third-party skills require an individual license and dependency review. The private skill corpus, personal state, raw research, credentials, and machine configuration are outside the public roadmap.
