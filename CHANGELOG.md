# Changelog

## 0.1.0 — 2026-10-21

First runnable public toolkit edition.

- Added the original standard-library evaluation runner and task linter from the maintained claude-os source.
- Added synthetic examples and CLI regression tests for completed, failed, and incomplete evaluations.
- Added a selected collection of attributed third-party review skills.
- Replaced the public overview with reproducible setup and explicit evaluation limits.
- Added automated Python checks and contribution/security guidance.
- Marked personal-runtime audit, hooks, and agent definitions as historical reference material.

The earlier July public edition was a control-layer snapshot that could not run standalone. This release supports the evaluator and examples; it does not publish or install the complete personal environment.
